# One Star for Monday

A one-star review of Monday, written as if Monday were a restaurant. One line, 19 words, plain text — a table, a dish and a bill that all went wrong.

> One star: waited an hour for a table, got Friday's leftovers, and Monday charged me for the whole week.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```

`main.ts` is plain Node with no dependencies and no network. It validates the line (1–180 characters, at most 25 words, a single line, not only whitespace) and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
